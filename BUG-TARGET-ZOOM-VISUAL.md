# БАГ: Zoom режим не увеличивает мишень визуально

**Дата:** 2024-08-19  
**Приоритет:** HIGH  
**Статус:** 🔴 Требует исправления  
**Связанный план:** PLAN-TARGET-ZOOM.md

---

## Описание проблемы

При переключении на zoom режим (🔍 7-10) **визуально не происходит увеличения мишени**.

**Текущее поведение:**
- Клик на кнопку 🔍 → меняется цвет центральной зоны (исчезает чёрный круг)
- Внешние кольца 1-6 исчезают
- НО размер центральной зоны 7-10 остаётся **таким же маленьким**
- Выстрелы не увеличиваются

**Ожидаемое поведение (как в фотоаппарате):**
- Клик на кнопку 🔍 → центральная зона 7-10 **увеличивается** и занимает всё доступное пространство viewBox
- Кольца 7, 8, 9, 10 становятся **визуально больше**
- Выстрелы **увеличиваются** пропорционально и остаются на своих местах относительно колец
- Эффект "приближения камеры" — как будто зум-объектив приблизил центр мишени

---

## Воспроизведение

1. Открыть тренировку
2. Сделать несколько выстрелов в зону 7-10
3. Кликнуть на кнопку 🔍 (zoom)
4. **Баг:** выстрелы остаются маленькими точками, центральная зона не увеличивается

---

## Анализ причины

### Текущая реализация (src/components/TargetCanvas.tsx):

```typescript
const VIEW = 160; // viewBox всегда 160x160
const SVG_TARGET_RECT = { left: 0, top: 0, width: VIEW, height: VIEW }; // константа

// В zoom7 режиме:
const outerRadius = zoomMode === 'zoom7' ? RING_D[7] / 2 : 80; // 29.75 vs 80

// SVG:
<svg viewBox={`0 0 ${VIEW} ${VIEW}`}>
  <circle cx={CENTER} cy={CENTER} r={outerRadius} fill="white" />
  // кольца 7-10 с теми же радиусами RING_D[7-10] / 2
</svg>
```

**Проблема:**
1. `viewBox` остаётся `0 0 160 160` — видимая область не меняется
2. `outerRadius = 29.75` — белый круг уменьшается до размера зоны 7
3. Координаты выстрелов НЕ масштабируются
4. `targetToScreen()` использует константный `SVG_TARGET_RECT` — не учитывает zoom

**Результат:** вместо увеличения центра мы просто **рисуем маленький круг** в том же viewBox.

---

## Решение

Нужно **масштабировать координаты** так, чтобы зона радиусом 29.75mm занимала те же 80 единиц viewBox, что и полная мишень.

### Вариант 1: Масштабирование через коэффициент (рекомендую)

**Коэффициент zoom:**
```typescript
const ZOOM_SCALE = zoomMode === 'zoom7' ? 80 / (RING_D[7] / 2) : 1.0;
// zoom7: 80 / 29.75 ≈ 2.69
// full:  1.0
```

**Изменения:**

1. **Координаты колец** масштабировать:
   ```typescript
   <circle r={RING_D[7] / 2 * ZOOM_SCALE} /> // 29.75 * 2.69 = 80
   <circle r={RING_D[8] / 2 * ZOOM_SCALE} /> // и т.д.
   ```

2. **Координаты выстрелов** масштабировать перед `targetToScreen`:
   ```typescript
   const scaledXh = shot.x * ZOOM_SCALE;
   const scaledYh = shot.y * ZOOM_SCALE;
   const sp = targetToScreen(scaledXh, scaledYh, SVG_TARGET_RECT);
   ```

3. **Координаты ввода** (tap/drag) демасштабировать после `screenToTarget`:
   ```typescript
   const target = screenToTarget(clientX, clientY, rect);
   const actualXh = target.xh / ZOOM_SCALE;
   const actualYh = target.yh / ZOOM_SCALE;
   ```

4. **Радиусы лабелей** масштабировать:
   ```typescript
   const ringLabels = zoomMode === 'zoom7'
     ? RING_LABELS_ZOOM7.map(l => ({ ...l, r: l.r * ZOOM_SCALE }))
     : RING_LABELS_FULL;
   ```

---

### Вариант 2: Динамический viewBox (сложнее)

```typescript
const viewBoxSize = zoomMode === 'zoom7' ? RING_D[7] : VIEW;
const viewBoxOffset = zoomMode === 'zoom7' ? CENTER - RING_D[7]/2 : 0;

<svg viewBox={`${viewBoxOffset} ${viewBoxOffset} ${viewBoxSize} ${viewBoxSize}`}>
```

**Минусы:**
- Сложнее, нужно пересчитывать центр
- SVG_TARGET_RECT тоже должен меняться
- Больше мест для ошибок
