# PLAN: Номер выстрела внутри маркера на мишени

## Задача
Каждый маркер выстрела на мишени должен показывать порядковый номер выстрела (`shotNumber`) внутри кружка.

## Решения по итогам вопросов

| Вопрос | Решение |
|---|---|
| Позиция номера | Внутри кружка (по центру) |
| Размер маркера | Адаптивный: обычный `r≈3`, последний `r≈4`, drag `r≈4` |
| Цветовая схема | Прежняя (белый/золотой/оранжевый круг + контрастный текст) |
| Zoom-режим | Номера отображаются везде, в т.ч. в zoom7 |

## Изменения в коде

### Файл: `src/components/TargetCanvas.tsx`

**Старые маркеры** (не последний, не drag):
```
r=0.9 — заменить на r_marker (под текст)
добавить <text> по центру (cx, cy) с shotNumber
```

**Последний выстрел**:
```
r=1.2 — заменить на r_marker
добавить <text>
```

**Drag (перетаскиваемый)**:
```
r=1.8 — заменить на r_marker
добавить <text> белым цветом
```

### Конкретные размеры

Все в единицах SVG viewBox (1 unit ≈ 1 mm):

| Тип | `r_marker` | `fontSize` | `textFill` |
|---|---|---|---|
| Старые (1…n-1) | 2.8 | 2.4 | `#333` (dark) |
| Последний | 3.5 | 2.8 | `#333` (dark) |
| Drag | 3.5 | 2.8 | `white` |

Шрифт: `font-weight: bold` для читаемости.  
Выравнивание: `textAnchor="middle"`, `dominantBaseline="central"`.

Двойная обводка остаётся (outer black stroke + colored fill) — просто увеличиваем `r`.

### Структура SVG для одного выстрела

```jsx
<g key={shot.id}>
  {/* outer black stroke */}
  <circle cx={sp.px} cy={sp.py} r={R_OUTER} fill="none" stroke="black" strokeWidth={0.6}/>
  {/* colored fill */}
  <circle cx={sp.px} cy={sp.py} r={R_INNER} fill={fillColor} stroke={strokeColor} strokeWidth={0.25}/>
  {/* shot number */}
  <text
    x={sp.px} y={sp.py}
    fontSize={fontSize}
    fill={textFill}
    textAnchor="middle"
    dominantBaseline="central"
    fontWeight="bold"
    style={{ userSelect: 'none', pointerEvents: 'none' }}
  >{shot.shotNumber}</text>
</g>
```

> `R_OUTER = r_marker + 0.5` (зазор для черной обводки)

## Порядок рендера

Не менять: старые выстрелы рисуются снизу, последний — поверх. Это уже так и есть.

## Влияние на zoom-режим

`ZOOM_SCALE` уже применяется к `sp.px/sp.py` — маркеры масштабируются вместе с мишенью.  
Размеры `r` и `fontSize` в единицах viewBox тоже масштабируются автоматически т.к. SVG viewBox не меняется — изменений для zoom не нужно, всё работает одинаково.
