# План: Переключатель режима отображения мишени

**Дата:** 2024-08-19
**Статус:** ✅ Выполнено
**Исполнитель:** worker (async run 18acffa5)

---

## 1. Описание функционала

Добавление возможности переключения между двумя режимами отображения мишени в тренировочном экране:

- **Полный режим (1-10):** текущее поведение — вся мишень с кольцами 1-10, радиус 80 мм
- **Zoom режим (7-10):** увеличенное отображение только зоны профи — кольца 7-10, радиус ~30 мм

**Обоснование:** Для профессиональных стрелков зона 1-6 не критична, увеличенный вид центральной зоны (7-10) даёт лучшую видимость и точность размещения выстрелов.

---

## 2. Пользовательский сценарий

1. Тренер открывает тренировку
2. Видит кнопку-переключатель в шапке экрана (рядом с номером выстрела)
3. Кликает по кнопке → мишень переключается между полным и zoom режимами
4. Настройка **глобальная** — сохраняется для всех тренировок всех спортсменов
5. Координаты выстрелов, scoring, история не меняются

### 3.2 TrainingScreen: загрузка настройки и UI переключатель

**Файл:** `src/screens/TrainingScreen.tsx`

**Изменения:**

1. Импортировать `readSettings`, `writeSettings` из `../db/settings`
2. Добавить состояние: `const [zoomMode, setZoomMode] = useState<'full' | 'zoom7'>('full')`
3. В `useEffect` при монтировании загрузить настройку:
   ```typescript
   const settings = await readSettings();
   setZoomMode(settings.targetZoomMode);
   ```
4. Обработчик переключения:
   ```typescript
   const toggleZoom = async () => {
     const newMode = zoomMode === 'full' ? 'zoom7' : 'full';
     setZoomMode(newMode);
     const settings = await readSettings();
     await writeSettings({ ...settings, targetZoomMode: newMode });
   };
   ```
5. Добавить кнопку в header (между `athleteName` и `shotNum`):
   ```typescript
   <button style={s.zoomBtn} onClick={toggleZoom}>
     {zoomMode === 'full' ? '🎯 1-10' : '🔍 7-10'}
   </button>
   ```
6. Передать `zoomMode` в `TargetCanvas`:
   ```typescript
   <TargetCanvas zoomMode={zoomMode} ... />
   ```

**Стиль кнопки:**
```typescript
zoomBtn: { 
  background: 'none', 
  border: '1px solid #ccc', 
  borderRadius: 6,
  padding: '4px 8px', 
  fontSize: 13, 
  cursor: 'pointer',
  color: '#1a1a2e'
}
```

### 3.3 TargetCanvas: двухрежимная отрисовка

**Файл:** `src/components/TargetCanvas.tsx`

**Изменения:**

1. Добавить пропс `zoomMode: 'full' | 'zoom7'` в интерфейс `Props`
2. Вычислить радиус внешнего круга в зависимости от режима:
   ```typescript
   const outerRadius = zoomMode === 'zoom7' ? RING_D[7] / 2 : 80;
   ```
3. Вычислить список колец для отрисовки:
   ```typescript
   const visibleOuterRings = zoomMode === 'zoom7' ? [] : [1, 2, 3, 4, 5, 6];
   ```
4. Вычислить список лабелей для отрисовки:
   ```typescript
   const visibleLabels = zoomMode === 'zoom7'
     ? RING_LABELS.filter(l => l.n >= 7)
     : RING_LABELS;
   ```
5. Заменить жёстко заданные значения на вычисленные:
   - Внешний белый круг: `r={outerRadius}`
   - Внешние кольца: `{visibleOuterRings.map(n => ...)}`
   - Лабели: `{visibleLabels.map(...)}`

**Важно:**
- `viewBox` остаётся `0 0 160 160`
- Центр остаётся `80, 80`
- Чёрная зона (до кольца 7) рисуется всегда: `<circle r={RING_D[7] / 2} fill="black" />`
- Координаты выстрелов (xh/yh) не меняются
- `transform.ts` (screenToTarget/targetToScreen) работают без изменений — они привязаны к viewBox

## 7. Ограничения и будущие улучшения

### Текущие ограничения

1. **Глобальная настройка** — один режим для всех тренировок
2. **Нет анимации** перехода между режимами
3. **Нет автоматического zoom** при хороших результатах

### Возможные улучшения (не в этом плане)

1. Привязка режима к конкретной тренировке (в `TrainingRecord`)
2. Smooth transition при переключении (CSS transform scale)
3. Автоматический zoom при avg > 9.5
4. Pinch-to-zoom жест на телефоне
5. Дополнительный режим "8-10" (ультра-zoom)

## 9. Безопасность и производительность

### Безопасность

- Нет новых XSS векторов (не используем dangerouslySetInnerHTML)
- Настройка валидируется при чтении (`'full' | 'zoom7'`)
- CSP не нарушается (нет inline стилей в SVG)

### Производительность

- Переключение режима — один IndexedDB write (~1-2ms)
- Render TargetCanvas не меняется по сложности
- В zoom режиме рисуем меньше элементов → slight perf gain
- Никаких дополнительных сетевых запросов
