# mushketon-coach

Офлайн PWA для тренера по пулевой стрельбе (ISSF, 10 м, пневматический пистолет).

Тренер смотрит на монитор электронной мишени и вручную вносит место попадания:
тап по мишени → перетаскивание для уточнения → живой десятичный ISSF-счёт →
отпускание фиксирует выстрел.

## Функционал

- Ручной ввод попадания: tap для примерного места, drag для точной корректировки.
- Десятичный счёт ISSF (10.0–10.9) считается сразу при вводе.
- Работа с несколькими спортсменами и переключение между ними из списка
  спортсменов без потери данных тренировок.
- Тренировка — произвольная последовательность выстрелов, можно продолжить позже.
- Правка последнего и более ранних выстрелов, отмена последнего добавленного.
- Комментарии (заметки) к выстрелам.
- Резервное копирование и восстановление данных одним JSON-файлом.
- Полностью офлайн: все данные хранятся локально на устройстве (IndexedDB).
- Нет бэкенда, нет аккаунтов, нет синхронизации и облачных сервисов.

## Как открыть приложение на телефоне

Откройте ссылку в браузере телефона: [https://sst1xx.github.io/mushketon-coach/](https://sst1xx.github.io/mushketon-coach/).

Чтобы добавить приложение на рабочий стол:

- **Android (Chrome):** откройте ссылку, нажмите `⋮` → **Добавить на главный экран** (или **Установить приложение**) и подтвердите.
- **iPhone (Safari):** откройте ссылку в Safari, нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.

После этого запускайте «Тренер» с рабочего стола как обычное приложение. Данные сохраняются локально на этом устройстве.
