# PLAN-AI-ANALYSIS.md — Анализ с AI (OpenRouter)

## 1. Цель

Добавить функцию «Анализ с AI»: тренер выбирает тренировки атлета, приложение формирует промпт
с данными о выстрелах и отправляет его в OpenRouter; ответ модели показывается в модальном окне.
Всё offline-first, ключ хранится локально, никаких новых бэкенд-зависимостей.

---

## 2. Пользовательский сценарий

```
SettingsScreen
  └─ [секция «Анализ с AI»]
       ├── Авторизация через OpenRouter (OAuth PKCE)
       │     → openrouter.ai/auth?callback_url=… → redirect с code → обмен на api-key
       │     Сохранить key в IndexedDB (settings.openrouterToken)
       ├── Выбор модели: выпадающий список бесплатных моделей (загружается из API)
       │     + поле «своя модель» для любой другой
       │     (default: nvidia/nemotron-3-super-120b-a12b:free)
       │     Сохранить в settings.aiModel
       └── [Запустить анализ] → открывает AiAnalysisModal
             └── Список тренировок текущего атлета с чекбоксами
                 (pre-selected: последние 3; кнопка «Выбрать все»)
                 [Анализировать] → одноразовый диалог согласия → spinner → ответ AI
```

## 4. OAuth PKCE (OpenRouter)

OpenRouter поддерживает OAuth PKCE без бэкенда:
```
https://openrouter.ai/auth?callback_url=<redirect_uri>&code_challenge=<challenge>&code_challenge_method=S256
```
После авторизации OpenRouter редиректит на `callback_url?code=<code>`.
Приложение ловит `code` при загрузке (`App.tsx`), обменивает на постоянный API-ключ через
`POST https://openrouter.ai/api/v1/auth/keys` и сохраняет в IndexedDB.

> `callback_url` = `window.location.origin + window.location.pathname`

**Хранение `code_verifier`:** в `localStorage` (не `sessionStorage`) с ключом
`or_pkce_verifier` и TTL 10 минут — иначе на iOS standalone OAuth redirect открывает
Safari с отдельным `sessionStorage`, и verifier теряется.

**После чтения `?code=`** немедленно вызвать `history.replaceState({}, '', location.pathname)`,
чтобы код не осел в истории браузера и не попал в service worker cache.

**Результат `/auth/keys`:** возвращает `{ key: 'sk-or-v1-…', user_id }` — это постоянный
API-ключ, не токен с TTL. Ошибка 401 означает «ключ отозван», не «протух».

### Ограничение iOS standalone
На iOS PWA в standalone-режиме полный redirect может не вернуться в контекст приложения.
Обязательно проверить на реальном устройстве перед релизом. Если не работает — fallback:
`window.open` + `postMessage` от opener.

## 5. Промпт (зашит в `buildPrompt.ts`)

> Тон и формат ответа уточняются в PLAN-AI-PROMPT-ATHLETE.md (обращение на «вы»,
> закрытый белый список допустимых чисел, практические рекомендации).

**Системный промпт** (RU):
```
Ты — тренер по пулевой стрельбе (ИССФ, воздушный пистолет 10 м).
Анализируй данные тренировок стрелка и давай конкретные рекомендации
по технике, психологической подготовке и планированию. Отвечай на русском.
```

**Пользовательский промпт** — компактный текстовый формат, **не JSON**.
Каждый выстрел — одна строка ~25 символов (~7 токенов).
5 тренировок × 20 выстрелов ≈ 100 строк ≈ 700–900 токенов входа.

Имя атлета **не передаётся** — вместо него «Стрелок» (приватность: free-модели
логируют промпты у провайдеров).

```
Стрелок

Тренировка 2025-07-10 (20 выст., сумма 207.4):
#  1  10.4  x=+1.2  y=-0.5
#  2   9.8  x=-3.1  y=+2.0
#  3  10.2  x=+0.8  y=-1.1
...

Тренировка 2025-07-08 (18 выст., сумма 185.3):
#  1   9.5  x=-4.2  y=+0.3
...

Дай анализ прогресса, выяви паттерны отклонений (куда уходят выстрелы,
кучность, динамика по ходу тренировки) и предложи конкретные упражнения.
```

Формат данных:
- Балл: `shot.score / 10` → ISSF decimal (10.4, 9.8, …)
- Координаты: `shot.x / 100`, `shot.y / 100` → мм, 1 знак после запятой, со знаком (+/-)
- X: положительный = правее центра, отрицательный = левее
- Y: положительный = выше центра, отрицательный = ниже
- Только `committed` выстрелы; `draft` игнорируются

## 6. Список моделей (`src/ai/models.ts` + `openrouter.ts`)

```ts
export const DEFAULT_MODEL = 'nvidia/nemotron-3-super-120b-a12b:free';
export type AiModel = { id: string; name: string };
```

Список моделей **загружается динамически** из OpenRouter API после авторизации:
```
GET https://openrouter.ai/api/v1/models
Authorization: Bearer <key>
```
Фильтрация:
- `pricing.prompt === '0'` AND `pricing.completion === '0'` — только полностью бесплатные
- `architecture.modality === 'text->text'` — только чат-модели (исключает Lyria и др.)

Сортировка: по `name` алфавитно. `DEFAULT_MODEL` выводится первым независимо от сортировки.

`fetchFreeModels()` в `src/ai/openrouter.ts` возвращает `AiModel[]`.
Принимает `origin` и `verifier` как параметры — не использует глобальные `window` внутри,
что позволяет тестировать в node-окружении.

Результат кешируется в `sessionStorage` на время сессии.

Поле «своя модель» — свободный текст под выпадающим списком, используется вместо выбранного.
При заполнении свободного поля выпадающий список показывает «Другая…».

**Фолбэк:** если `DEFAULT_MODEL` не найден в загруженном списке — подставить первую
модель из списка (список меняется, модель может исчезнуть).

## 9. Обработка ошибок

| Сценарий | Поведение |
|---|---|
| Нет ключа | Кнопка «Запустить анализ» неактивна + подсказка «Войдите через OpenRouter» |
| Offline (`!navigator.onLine`) | Показать сообщение до отправки запроса |
| Сетевая ошибка / таймаут | Сообщение в модальном окне, кнопка «Повторить» |
| 401 | «Ключ отозван, войдите снова» + сброс токена из IndexedDB |
| 402 | «Недостаточно кредитов на аккаунте OpenRouter» |
| 429 | «Превышен лимит запросов, попробуйте позже» (у free-моделей низкие дневные лимиты) |
| Пустой `choices[]` | «Модель не вернула ответ, попробуйте другую модель» |
| Нет тренировок / выстрелов | Кнопка «Анализировать» неактивна |
| Запрос отменён пользователем | Тихо закрыть spinner |

## 10. Хранение данных (IndexedDB settings)

> `SettingsKey` живёт в `src/db/schema.ts` — добавлять новые ключи туда.

| Ключ | Тип | Описание |
|---|---|---|
| `openrouterToken` | `string` | Постоянный API-ключ `sk-or-v1-…` |
| `aiModel` | `string` | ID выбранной модели (default: `nvidia/nemotron-3-super-120b-a12b:free`) |
| `aiConsentGiven` | `boolean` | Флаг одноразового согласия на отправку данных |

> Нет `openrouterTokenExpiry` — `/auth/keys` не возвращает срок истечения.

**Важно:** `exportBackup` (`backupService.ts`) собирает фиксированный объект из явно
перечисленных ключей — `openrouterToken` и `aiConsentGiven` в бэкап **не попадут**
(ключ в бэкапе = уязвимость).

## 11. CSP — одобренное исключение

AGENTS.md §1 правило 4 запрещает запросы к другим origin. **Явное одобрение пользователя**
получено: добавить `https://openrouter.ai` в `connect-src` в двух местах:

- `public/_headers` (Cloudflare Pages)
- `index.html` `<meta http-equiv="Content-Security-Policy">` (GitHub Pages, где `_headers` игнорируется)

Без этой правки все fetch к OpenRouter заблокирует браузер.
