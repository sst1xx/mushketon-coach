# PLAN-DIARY-AFFORDANCE — единообразное редактирование в Дневнике

Статус: approved (see conversation with user + oracle review). Формат и порядок
данных в Дневнике не меняются — меняется только визуальный/интерактивный
язык редактирования замечаний.

## 1. Проблема

Дневник (`RemarksScreen`, `TrainingRemarksScreen`) показывает три вида
замечаний — общее (тренировка/упражнение), замечание серии (ПП-3) и
замечание к выстрелу — каждое со своим способом редактирования:

- замечание к выстрелу: иконки `✎`/`✕`, редактирование через `Modal` (textarea
  в диалоге);
- общее замечание: клик по всему текстовому блоку, отдельного экрана
  редактирования, без явной иконки `✎`;
- замечание серии на верхнем уровне дневника (`RemarksScreen`): вообще не
  редактируется — только текст или заглушка «Нет общего замечания»;
- пустые состояния оформлены по-разному (пунктирная кнопка «+ Добавить…» для
  общего замечания против пассивного текста для серии).

`TrainingRemarksScreen` дополнительно импортирует CSS-модуль
`RemarksScreen.module.css` напрямую (`diaryStyles`) — нежелательная
перекрёстная зависимость между экранами.

## 2. UX-контракт (после изменения)

Единая строка замечания (для общего, серийного и shot-замечания):

```
[необязательная метка уровня, напр. «Общее замечание серии 3»]
Текст замечания                              [✎] [✕]
Метка выстрела · дата   (только для shot-замечаний, кликабельна → мишень)
```

Правила:

1. Клик по тексту замечания → открыть редактор этого замечания.
2. Клик по мета-строке (только у shot-замечаний: «Выстрел №N · 10.4 · дата»)
   → переход к мишени на этом выстреле (существующее поведение, сохраняется).
3. `✎` — явная кнопка «редактировать», ведёт туда же, куда клик по тексту.
4. `✕` — явная кнопка «удалить», всегда через модалку подтверждения.
5. Пустое состояние всегда — пунктирная кнопка «+ Добавить …», единый стиль
   для общего, серийного и (там, где применимо) любого другого замечания.
   Никогда не показываем пассивный неинтерактивный текст-заглушку.
6. Редактор:
   - Общее замечание тренировки/упражнения и замечание серии — уже
     полноэкранный экран (`GeneralRemarkScreen`), остаётся им, дополнительно:
     кнопка «Сохранить» блокируется на пустом тексте (сейчас пустой текст
     тихо удаляет запись через `saveGeneralComment`/`saveSeriesComment` —
     это и есть скрытое небезопасное поведение, которое устраняется).
   - Замечание к выстрелу при редактировании из дневника переезжает с
     `Modal` на новый полноэкранный экран `ShotRemarkEditorScreen`, той же
     визуальной формы (заголовок, мета, textarea, «Отмена»/«Сохранить»,
     кнопка неактивна на пустом тексте).
   - Создание shot-замечаний остаётся исключительно с экрана мишени
     (`TrainingScreen`) — это правило не меняется, `ShotRemarkEditorScreen`
     только редактирует уже существующую запись.
7. Удаление всегда только через отдельное модальное подтверждение (`Modal`
   с danger-действием) — независимо от типа замечания. Сохранение никогда
   не удаляет запись неявно.

## 3. Общий компонент

Новый переиспользуемый компонент `src/components/RemarkRow.tsx` +
`RemarkRow.module.css`:

- `RemarkRow` — заполненная строка: label?, text, meta?(строка/кнопка),
  onOpenEditor, onOpenMeta?, onEdit, onDelete, nested?(отступ для вложенных
  строк серии/выстрела).
- `RemarkRowEmpty` — пустое состояние: addLabel, onAdd, nested?.

Используется в обоих экранах дневника вместо дублирующейся разметки,
устраняя необходимость `TrainingRemarksScreen` импортировать
`RemarksScreen.module.css`.

## 4. Изменения по файлам

- `src/components/RemarkRow.tsx`, `RemarkRow.module.css` — новый общий
  компонент (см. §3).
- `src/screens/ShotRemarkEditorScreen.tsx`, `.module.css` — новый
  полноэкранный редактор shot-замечания (визуально повторяет
  `GeneralRemarkScreen`), с кнопкой «Сохранить», отключённой на пустом
  тексте.
- `src/screens/GeneralRemarkScreen.tsx` — точечно: кнопка «Сохранить»
  дизейблится на пустом тексте (без изменения порядка хуков — тесты жёстко
  завязаны на индексы `useState`).
- `src/screens/RemarksScreen.tsx` — все строки замечаний (общее, серийное,
  shot, вложенные под серию) переведены на `RemarkRow`/`RemarkRowEmpty`;
  редактирование shot-замечания теперь через push на
  `shotRemarkEditor` вместо `Modal`; замечание серии на верхнем уровне
  дневника становится редактируемым (клик/✎ → редактор конкретной серии,
  ✕ → подтверждение удаления через `deleteSeriesComment`).
- `src/screens/TrainingRemarksScreen.tsx` — то же самое; убран импорт
  `RemarksScreen.module.css`; своя разметка сведена к обёрткам поверх
  `RemarkRow`.
- `src/App.tsx` — новый тип экрана `shotRemarkEditor` (athlete, training,
  comment, shot?) с push/pop; `onOpenGeneralRemark` из `RemarksScreen`
  получает необязательный `seriesNumber` (по умолчанию `null`, сохраняя
  текущее поведение вызовов с одним аргументом).
- Тесты: обновлены/дополнены `remarksScreenDiary.test.tsx`,
  `trainingRemarksScreen.render.test.tsx`, `generalRemarkScreen.render.test.tsx`,
  `App.test.tsx`; новые `remarkRow.test.tsx`,
  `shotRemarkEditorScreen.render.test.tsx`.

## 5. Явно вне рамок

- Создание shot-замечаний вне экрана мишени — не добавляется.
- Изменение формата/порядка данных в дневнике — не производится.
- Общий/серийный редактор не объединяется в один React-компонент с
  shot-редактором (хук-ордер существующих тестов `GeneralRemarkScreen`
  делает это рискованным); объединение — только на уровне визуального
  языка и структуры экрана, не общего кода компонента.
