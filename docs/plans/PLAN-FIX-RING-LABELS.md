# План: исправить геометрию подписей колец мишени

## Диагноз Oracle
Предыдущий фикс устранил только `n - 1`, но оставил две проблемы:
- `computeRingLabels` возвращает метку `10`, хотя спецификация требует метки только 1–9;
- радиус `RING_D[n] / 2 - 2.5` и направленные SVG-якоря (`start/end/auto/hanging`) смещают визуальный центр цифры относительно полосы кольца.

## Исправление
В `src/components/TargetCanvas.tsx`:
1. Удалить метку 10 из `full` и `zoom7`.
2. Для N=1…9 использовать центр полосы кольца:
   `r = (RING_D[N] / 2 + RING_D[N + 1] / 2) / 2 = RING_D[N] / 2 - 4`.
   В `zoom7` применить `ZOOM7_SCALE`.
3. Для всех четырёх направлений использовать `textAnchor="middle"` и `dominantBaseline="central"`; направление меняет только знак координат.
4. Сохранить цвета: 7–9 белые, 1–6 чёрные.

## Тесты
Обновить `src/components/targetLabels.test.ts`:
- full: `[9,8,7,6,5,4,3,2,1]`, без 10;
- zoom7: `[9,8,7]`, без 10;
- проверить точный центр каждой 8-мм полосы и масштабирование;
- сохранить проверки цветов и отсутствия обрезания.

## Ограничения
Не менять scoring, transform, БД, маркеры выстрелов или pointer events.

## Проверка и приёмка
- `npm test` проходит;
- `npm run build` проходит;
- в full и zoom7 цифры 1–9 визуально центрированы в своих полосах;
- цифра 10 отсутствует.

После проверки выполнить деплой Cloudflare Pages отдельной командой пользователя.
