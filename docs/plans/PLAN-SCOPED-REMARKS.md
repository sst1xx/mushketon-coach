# PLAN-SCOPED-REMARKS — замечания, ограниченные текущей серией/упражнением

## Проблема

Сейчас, чтобы посмотреть или добавить замечание к конкретной серии/упражнению,
тренер должен открыть общий дневник «Все замечания», где записи разных
тренировок идут одна за другой. Нет прямого перехода из экрана тренировки
именно к замечаниям текущего (или выбранного в ПП-3) элемента.

## Решение

1. В шапке `TrainingScreen` — отдельная кнопка с однозначной подписью:
   - `Замечания серии` — режим `series`;
   - `Замечания упражнения` — режим `pp3` при просмотре всего упражнения;
   - `Замечания серии N` — режим `pp3` при выбранной серии (`selectedSeriesView`
     или текущая `pp3CurrentSeries`).
   Кнопка доступна всегда, даже если замечаний ещё нет.

2. Новый экран `TrainingRemarksScreen` — «scoped» дневник одной
   тренировки/серии:
   - показывает только выстрелы выбранного диапазона (для ПП-3 — по
     `getPp3SeriesShotNumberRange`, границы 10/11 и т.д., как в
     `trainingMode.ts`; для `series`/`legacy` — все выстрелы тренировки);
   - показывает общее замечание тренировки (`generalComments`, один на
     `trainingId`); для ПП-3 подписывает его явно: «Общее замечание по
     упражнению» — так как оно относится ко всему упражнению, а не к
     отдельной серии;
   - позволяет добавить общее замечание, если его ещё нет;
   - позволяет редактировать/удалять существующее общее замечание;
   - показывает замечания к выстрелам этого диапазона, позволяет их
     редактировать/удалять; **новые** замечания к выстрелам здесь не
     создаются — это делается только с экрана мишени (`TargetCanvas` /
     `TrainingScreen`), поэтому выстрелы без существующего замечания на этом
     экране не показываются вовсе;
   - содержит переход «Открыть все замечания» — уводит в существующий
     `RemarksScreen` (полный дневник спортсмена);
   - строка с датой и результатом (например, «29.08.2026, 20:41 · 10
     выстрелов · 66 (70.1)») оформлена как ссылка, а не отдельная кнопка —
     переиспользует тот же `onBack`, что и «Назад», и возвращает в
     `TrainingScreen` с тем же выбранным `restoreSeriesView`/
     `selectedSeriesView`, то есть открывает экран мишени именно этой
     серии/упражнения; отдельной кнопки «Просмотр мишени» нет, чтобы не
     перегружать интерфейс; не заводит отдельный маршрут и не путается с
     кнопкой «Просмотр» в completion-modal `TrainingScreen` (та относится к
     правке последнего выстрела перед завершением);
   - «Назад» возвращает в ту же тренировку с тем же выбранным
     `selectedSeriesView`.

3. `App.tsx` — новый маршрут:
   ```ts
   {
     name: 'trainingRemarks';
     athlete: AthleteRecord;
     training: TrainingRecord;
     seriesNumber: number | null; // null = вся тренировка/упражнение целиком
     returnTo: 'training';
   }
   ```
   При возврате восстанавливает `TrainingScreen` с прежним
   `selectedSeriesView` (передаётся через проп, не теряется).

4. `commentRepo` — добавить `listCommentsByTraining(trainingId)` (индекс уже
   существует), чтобы не тянуть все замечания спортсмена ради одной
   тренировки.

5. `RemarksScreen` уже сгруппирован по тренировкам (карточка на тренировку) —
   релевантный функционал не меняется, помимо добавления перехода из
   `TrainingRemarksScreen` обратно в него.

## Не меняется

- `GeneralRemarkScreen` — существующий сценарий сразу после завершения
  («Просмотр / Замечания / Начать новую») продолжает работать как есть и
  использует прежний маршрут `generalRemark`. Новый scoped-экран — это
  дополнительная точка входа к тем же данным (`generalComments`), а не
  замена.
- Комментарии к выстрелам (`comments` store) и их API не меняются, кроме
  добавления одной read-функции.
- Схема IndexedDB не меняется — оба необходимых индекса (`comments.trainingId`,
  `generalComments.trainingId`-как-ключ) уже существуют.
- Completion-модалка (`showCompletedModal`) и её три действия не меняются.

## Тесты

- `trainingMode`-фильтрация: серия 1 показывает только выстрелы 1–10, серия 2
  — 11–20 (границы).
- Заголовок кнопки в шапке: «Замечания серии» / «Замечания упражнения» /
  «Замечания серии N».
- Кнопка доступна и без единого замечания у элемента.
- Общее замечание ПП-3 показывается с пометкой «Общее замечание по
  упражнению» на scoped-экране.
- Переход «Открыть все замечания» ведёт в `RemarksScreen`.
- Возврат из scoped-экрана восстанавливает `selectedSeriesView`.
- Существующие тесты `GeneralRemarkScreen`, `trainingScreenCompletionModal`,
  `remarksScreenDiary` остаются зелёными без изменений поведения.
