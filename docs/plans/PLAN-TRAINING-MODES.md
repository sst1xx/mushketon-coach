# План: режимы «Новая серия» и «Новое упражнение ПП-3»

## Статус

План согласован. Реализация кода этим планом не начинается до отдельной передачи задачи worker'у.

## Цель

Убрать неоднозначное название «+ Новая тренировка» и разделить запуск двух сценариев:

1. **Новая серия** — одна серия из 10 выстрелов.
2. **Новое упражнение ПП-3** — одно упражнение из 6 последовательных серий по 10 выстрелов, всего 60 выстрелов.

## Зафиксированные решения

- В интерфейсе используется одна кнопка `+ Новое`, при нажатии открывается модальное окно с двумя действиями: `Серия` и `Упражнение ПП-3`.
- Для ПП-3 после постановки каждого 10-го выстрела (10, 20, 30, 40, 50) блок серии на мишени остаётся видимым и редактируемым — переключения не происходит. Переход на новый блок происходит при постановке следующего выстрела (11-й, 21-й, 31-й, 41-й, 51-й), после чего на мишени отображается только новый блок. После 60-го выстрела на мишени остаётся видимым блок 51–60.
- После 60-го выстрела упражнение завершается.
- После завершения показывается кнопка `Начать новую`, открывающая модальное окно с двумя вертикальными действиями: `Серия` и `Упражнение ПП-3`.
- Undo последнего выстрела разрешён после достижения лимита: после отмены запись снова становится активной.
- На экране списка блоков ПП-3 можно выбрать любую завершённую серию для просмотра и редактирования её выстрелов на мишени; новые выстрелы при этом всё равно добавляются только в текущую (последнюю незавершённую) серию, а не в выбранную для просмотра.
- Старые записи не мигрируются и остаются доступными для просмотра и продолжения.
- ПП-3 хранится как одна запись упражнения, а не как шесть отдельных тренировок.
- Шесть блоков серий ПП-3 отображаются на экране списка; на экране мишени показываются текущая серия и общий прогресс.
- Режим выводится из существующего `targetShotCount`: `10` — серия, `60` — ПП-3, `null/undefined` — legacy-запись без лимита. Новое поле режима не добавляется.
- В ПП-3 отображаются общий прогресс и итоги отдельных завершённых серий.
- Фиксированные режимы «Серия» и «ПП-3» добавляются в продуктовые правила; старые безлимитные записи сохраняются.
- Логика scoring и geometry остаётся чистой и не изменяется.

## Текущее состояние проекта

В проекте уже есть инфраструктура для ограничения числа выстрелов через `targetShotCount`, проверки лимита при создании draft-выстрела и автоматического завершения записи после достижения лимита. Поэтому изменение схемы IndexedDB не планируется.

Перед реализацией необходимо подтвердить фактическое состояние рабочей ветки и проверить существующие типы/репозитории, не предполагая изменения схемы без необходимости.

## Объём изменений

### 1. Создание серии и ПП-3

Изменить экран списка тренировок:

- заменить все пользовательские подписи `+ Новая тренировка`;
- добавить две кнопки с отдельными обработчиками;
- создавать запись с лимитом 10 или 60 выстрелов;
- сохранять тип режима, если существующей модели недостаточно для однозначного отображения режима.

Предпочтительно не добавлять модальное окно, если две постоянные кнопки позволяют выбрать режим напрямую.

Кнопки должны располагаться **вертикально**, каждая на всю доступную ширину. Не планировать размещение двух длинных подписей в одну строку: на телефоне шириной 320–375 px после safe-area отступов доступно примерно 288–343 px, поэтому вариант в две колонки создаёт риск переноса текста и уменьшения удобной области нажатия. Существующий `.addBtn` уже использует `width: 100%` и минимальную высоту touch-target, его можно переиспользовать или вынести в контейнер с вертикальным `gap`.

После завершения текущего упражнения не размещать две длинные кнопки в трёхслотовом toolbar. Использовать кнопку `Начать новую`, которая открывает модальное окно; внутри модального окна кнопки идут вертикально.

Критерий мобильной вёрстки: на viewport 320 px обе кнопки полностью видимы по ширине, текст не обрезается и не выходит за границы; кнопки идут одна под другой и сохраняют высоту не менее 44 px.

### 2. Экран текущего упражнения

Для обычной серии показывать:

- название «Серия»;
- прогресс `N/10 выстрелов`;
- состояние завершения после 10-го выстрела.

Для ПП-3 показывать:

- название «ПП-3»;
- номер текущей серии: `Серия X из 6`;
- прогресс текущей серии `N/10`;
- общий прогресс `N/60`;
- заметный переход к следующей серии после 10-го выстрела.

Переход не должен создавать новую запись или сбрасывать упражнение. На мишени в любой момент отображаются выстрелы только одного блока серии: либо текущей (по умолчанию), либо выбранной вручную для просмотра/редактирования завершённой серии — переключение блока при выборе из списка не влияет на то, в какую серию добавляется следующий выстрел.

### 3. Блоки серий ПП-3

Отображать шесть блоков:

```text
Серия 1   10/10   итог
Серия 2    7/10   текущая
Серия 3    0/10
Серия 4    0/10
Серия 5    0/10
Серия 6    0/10
```

Номер серии вычисляется по committed-выстрелам, отсортированным по `shotNumber`: каждые 10 выстрелов образуют один блок. Draft-выстрел не входит в прогресс `N/10`, но относится к текущей серии. Для текущей незавершённой серии показывать текущий результат или нейтральное состояние согласно существующему UX итогов; не вводить отдельную сущность серии без необходимости. Итоги форматировать существующим `formatTrainingTotal`.

### 4. Список упражнений

Для новых записей показывать понятные названия и прогресс:

- `Серия · N/10`;
- `ПП-3 · X/6 серий · N/60 выстрелов`.

Существующие записи отображать обратно совместимым способом, без принудительной миграции.

### 5. Домен и тесты

Проверить и при необходимости минимально дополнить:

- создание серии с лимитом 10;
- создание ПП-3 с лимитом 60;
- переход с 10-го на 11-й выстрел;
- завершение после 60-го выстрела;
- запрет 61-го выстрела;
- вычисление блока серии;
- сохранение и продолжение незавершённого ПП-3;
- backup/restore режима и лимита;
- отображение старых записей.

Не менять scoring, transform и unrelated UI.

## Критерии приёмки

- На всех новых сценариях нет подписи `+ Новая тренировка`.
- Нажатие `Серия` создаёт серию максимум на 10 выстрелов.
- Нажатие `Упражнение ПП-3` создаёт ПП-3 на 60 выстрелов.
- После постановки 10-го (20-го, 30-го, 40-го, 50-го) выстрела блок серии на мишени остаётся прежним и редактируемым; переключение на новый блок происходит только при постановке следующего выстрела (11-й, 21-й и т.д.). После 60-го выстрела на мишени остаётся блок 51–60.
- Завершённую серию можно выбрать из списка блоков для просмотра и редактирования её выстрелов на мишени; новый выстрел при этом всё равно добавляется в текущую серию упражнения.
- После шестой серии добавление выстрела невозможно, упражнение отмечено завершённым. На границах серий 10, 20, 30, 40 и 50 показывается следующий блок, но упражнение не завершается и модал завершения не открывается. После 60-го выстрела Undo последнего созданного выстрела возвращает упражнение в состояние 59/60 и снова разрешает ввод.
- Один ПП-3 отображается как одно упражнение с шестью блоками серий.
- Незавершённое ПП-3 можно закрыть и продолжить без потери прогресса.
- Старые записи продолжают открываться и работать.
- Все существующие тесты проходят; добавлены тесты для ПП-3.
- Сборка TypeScript/Vite проходит.
