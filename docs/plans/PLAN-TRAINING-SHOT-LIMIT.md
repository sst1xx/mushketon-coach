# План: Лимит 10 выстрелов для новых тренировок

**Дата:** 2024-08-21
**Статус:** ✅ Выполнено
**Исполнитель:** worker

---

## 1. Описание функционала

1. **Лимит 10 выстрелов** применяется только для **новых** тренировок (`targetShotCount: 10`).
2. **Автоматическое завершение:** после сохранения 10-го выстрела тренировка автоматически завершается (`completedAt` заполняется текущим временем).
3. **Режим завершённой тренировки:**
   - Разрешено редактировать (перемещать) существующие выстрелы.
   - Разрешено удалять / отменять выстрелы (undo).
   - Запрещено добавлять новые выстрелы (тап по пустому полю мишени игнорируется).
4. **Старые тренировки:** не имеют лимита (`targetShotCount: undefined` / `null`) и не блокируют добавление новых выстрелов, пока не завершены вручную.
5. **UI:**
   - Счётчик выстрелов в шапке `TrainingScreen`: для лимитированных тренировок отображает `Выстрелы: N / 10`, для безлимитных — `Выстрелы: N`.
   - При фиксации 10-го выстрела (и при просмотре завершённой лимитированной тренировки) показывается предупреждение/сообщение о завершении тренировки и предложение создать новую.

## 2. Технические решения

### 2.1 Схема БД (`src/db/schema.ts`)
- Расширить интерфейс `TrainingRecord` опциональным полем:
  ```typescript
  export interface TrainingRecord {
    id: string;
    athleteId: string;
    startedAt: string;
    completedAt: string | null;
    nextShotNumber: number;
    updatedAt: string;
    targetShotCount?: number | null;
  }
  ```

### 2.2 Domain (`src/domain/trainingRepo.ts`)
- В `createTraining` по умолчанию задавать `targetShotCount: 10`.
- Добавить функцию `completeTraining(id: string, clientEpoch: number): Promise<TrainingRecord>`.

### 2.3 Backup Service (`src/domain/backupService.ts`)
- В `validateBackup` учесть опциональное поле `targetShotCount` (number > 0 или undefined/null).

### 2.4 TrainingScreen (`src/screens/TrainingScreen.tsx`)
- Хранить актуальное состояние тренировки `currentTraining`.
- Отслеживать количество сохранённых (`committed`) выстрелов: `committedCount`.
- При фиксации выстрела (`handleDragEnd`): если `currentTraining.targetShotCount` задан и после сохранения количество выстрелов достигает `targetShotCount`, автоматически вызвать `completeTraining(training.id, ep)` и обновить `currentTraining`.
- В `handleDragStart`: если `currentTraining.completedAt !== null` и `!isExisting`, запретить создание драфта (игнорировать добавление новых выстрелов).
- Перемещение существующих выстрелов (`isExisting: true`) и отмена (`handleUndo`) остаются доступными.
- В шапке отображать счётчик: `Выстрелы: ${committedCount} / ${limit}` (или `Выстрелы: ${committedCount}`).
- Отображать диалог / баннер завершения тренировки с кнопкой «Новая тренировка».

### 2.5 Навигация (`src/App.tsx`)
- Передать в `TrainingScreen` обработчик создания/перехода на новую тренировку `onNewTraining`, чтобы при нажатии кнопки «Новая тренировка» пользователь сразу переходил к новой серии.

## 3. План тестирования
- Unit-тесты domain:
  - Создание тренировки с `targetShotCount: 10`.
  - Завершение тренировки через `completeTraining`.
  - Совместимость со старыми тренировками без `targetShotCount`.
  - Валидация бэкапа с `targetShotCount`.
- UI/логические проверки:
  - Запрет создания нового выстрела в завершённой тренировке при сохранении возможности редактирования существующих.
  - Автоматическое завершение на 10-м выстреле.
