# План: видимость и масштаб цифр на мишени

**Статус:** На согласовании

## 1. Проблема

В `TargetCanvas` подписи колец вычисляются с разными правилами для полной и увеличенной мишени:

- в режиме `full` внешняя подпись может выходить за границы SVG `viewBox` (в частности, цифра возле кольца 9 в текущем отображении);
- в режиме `zoom7` размер шрифта обратно пропорционален увеличению (`7 / ZOOM_SCALE`), поэтому цифры становятся визуально слишком маленькими;
- отображаемое значение сейчас сдвинуто на единицу (`{n - 1}`), что не соответствует номеру кольца, заданному в данных меток.

## 2. Пользовательский результат

1. На полной мишени все подписи видимых колец полностью помещаются внутри её границ по всем четырём сторонам.
2. В увеличенном режиме подписи зоны 7–10 остаются крупными и читаемыми, не уменьшаясь из-за масштаба.
3. Каждая подпись показывает фактический номер своего кольца.
4. Геометрия мишени, координаты выстрелов, подсчёт очков и жесты не меняются.

## 3. Техническое решение

**Файл:** `src/components/TargetCanvas.tsx`

- Ввести отдельные параметры расположения и размера подписей для `full` и `zoom7`.
- Для полной мишени ограничить радиус размещения подписи доступной областью `viewBox` с учётом габарита текста, чтобы внешние цифры не обрезались.
- Для `zoom7` использовать размер шрифта в координатах SVG, который сохраняет требуемый визуальный размер после масштабирования (не делить его на `ZOOM_SCALE`).
- Исправить вывод текста с `{n - 1}` на `{n}`.
- Не изменять `viewBox`, `ZOOM_SCALE`, преобразование координат и структуру данных.

## 4. Изменяемые файлы

| Файл | Изменение |
|---|---|
| `src/components/TargetCanvas.tsx` | Логика размеров, безопасных позиций и значения подписей колец. |

## 5. Проверка

### Автоматическая

```bash
npm test
npm run build
```

### Ручная

1. Открыть режим `1–10`: убедиться, что все цифры 1–9 видны целиком сверху, снизу, слева и справа.
2. Переключить на `7–10`: проверить, что цифры 7–10 крупные, читаемые и не выходят за края.
3. Проверить соответствие подписи кольцу: 7 обозначает кольцо 7, 8 — кольцо 8 и т. д.
4. Добавить и перетащить выстрел в обоих режимах: позиция и текущий счёт должны остаться корректными.

## 6. Критерии приёмки

- На полной мишени нет обрезанных цифр, включая самые внешние.
- В zoom-режиме цифры не выглядят меньше, чем в полном режиме из-за преобразования масштаба.
- Номера подписей совпадают с кольцами.
- Сборка и тесты проходят.

## 7. Откат

Изменение локально в одном UI-файле: откатить правку `TargetCanvas.tsx` и удалить этот план, если результат не будет одобрен.
